# Plan: AI Lead Intelligence Platform — Hoja de Ruta 2026

## Resumen Ejecutivo

 Plataforma B2B de ventas impulsada por IA que descubre empresas en tiempo real (scraping geolocalizado), enriquece contactos con waterfall multi-proveedor, justifica con lenguaje natural por qué cada empresa es un lead válido, y ejecuta outreach multicanal (email + WhatsApp).

**Ventaja competitiva actual:** Frescura de datos (scraping real-time vs BD estáticas), justificación AI narrativa (vs scoring numérico opaco), canal WhatsApp nativo (ignorado por enterprise).

**Objetivo de este plan:** Evolucionar de prototipo funcional a plataforma competitiva 2026, cerrando la brecha con Apollo, Clay, Artisan, 11x y Seamless.ai.

## Pilares Estratégicos

### PILAR 1: Entregabilidad & Escalabilidad (Crítico)
*Referencia: Smartlead, Instantly, Instantly.ai*

Sin esto, las campañas caen en spam y la plataforma no escala.

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **Inbox Rotation** | Permitir conectar múltiples cuentas SMTP. Rotar envíos automáticamente (max 30/día por cuenta) |
| P0 | **Motor de Warmup** | Sistema de calentamiento automático: intercambia correos simulados entre cuentas para generar reputación |
| P0 | **Verificación SMTP en tiempo real** | Validar deliverability justo antes de envío (objetivo 95% precisión) |
| P1 | **Dominios secundarios** | Permitir agregar dominios de respaldo para envío |
| P1 | **Monitoreo de reputación** | Dashboard con score de dominio, alertas de blacklist |

### PILAR 2: Autonomía del Agente IA (Diferenciador)
*Referencia: Artisan (Ava), 11x (Alice)*

Mover de "herramienta asistida" a "agente semi-autónomo".

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **Dial de Autonomía** | 3 niveles: 1) Revisar cada mensaje, 2) Autónomo excepto objeciones, 3) Piloto automático total |
| P0 | **Knowledge Base** | Entrenar IA con PDFs/URLs/scripts del cliente para responder objeciones automáticamente |
| P1 | **Manejo de objeciones** | Detectar "es muy caro", "ya tenemos proveedor" y responder con knowledge base |
| P1 | **Soporte multiidioma** | Detectar idioma del lead y responder en su idioma nativo |
| P2 | **Resumen post-conversación** | AI genera resumen + próxima acción sugerida |

### PILAR 3: Enriquecimiento Inteligente (Optimización costos)
*Referencia: Clay, UpLead*

Implementar Stop-on-Success para no gastar créditos innecesarios.

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **Stop-on-Success estricto** | Panel de configuración de orden de proveedores. Secuencial: IA gratis → baratos → caros |
| P0 | **Verificación previa WhatsApp** | Verificar silenciosamente si número tiene cuenta activa antes de campaña (evita reportes spam) |
| P1 | **Extensión Chrome (LinkedIn Overlay)** | Ver datos enriquecidos y añadir a secuencias mientras navega LinkedIn |
| P2 | **WebSights (Identificación Inbound)** | Rastreador IP para identificar empresas que visitan la web del cliente |

### PILAR 4: Scoring Paramétrico + Justificación (UX Superior)
*Referencia: Prospect Hub, Clay*

Combinar lo mejor de ambos: scoring ajustable + explicación AI.

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **Scoring con deslizadores** | Usuario ajusta peso de cada criterio: "sin web" (+45pts), "+100 reseñas" (+20pts), etc. |
| P0 | **Justificación AI visible** | "Coincide con tu búsqueda de 'X' porque no tiene sitio web pero sí presencia en Instagram" |
| P1 | **Filtros por señal digital** | Filtrar por: tiene/no tiene web, CMS detectado, SSL, velocidad web, presencia social |
| P2 | **Lookalike expansion** | "Encuentra empresas similares a este lead" basado en signals |

### PILAR 5: Prospección Local Avanzada (Nicho)
*Referencia: Prospect Hub*

Explotar el nicho local que los enterprise ignoran.

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **Agenda + Rutas GPS** | Calendario integrado. Generar ruta óptima Google Maps para visitas físicas |
| P0 | **Mapa de calor** | Visualizar densidad de leads por zona en el mapa |
| P1 | **Itinerario del comercial** | "Hoy tienes 3 visitas en zona norte, ruta optimizada: link Google Maps" |
| P2 | **Check-in geolocalizado** | Registrar visita física con GPS para métricas de efectividad |

### PILAR 6: Conectividad Next-Gen (Infraestructura)
*Referencia: Seamless.ai, Clay*

| Prioridad | Feature | Implementación |
|-----------|---------|---------------|
| P0 | **MCP Server funcional** | Exponer datos vía MCP para que agentes externos (Claude, ChatGPT) consulten tu BD |
| P0 | **Form API (Inbound)** | API para conectar formularios web. AI califica leads entrantes, filtra spam |
| P1 | **CRM Sync bidireccional** | Sincronización con HubSpot/Salesforce: deduplicación, mapeo de campos |
| P1 | **API webhooks** | Notificaciones en tiempo real: nuevo lead, email abierto, reunión agendada |
| P2 | **Extensión Chrome completa** | Sidebar con datos del lead mientras navega LinkedIn/web de empresa |

## Ventajas Competitivas a Mantener

1. **Frescura de datos**: Scraping real-time vs BD estáticas (30% degradación anual)
2. **Justificación AI narrativa**: Reducir fricción cognitiva vs scoring opaco
3. **WhatsApp nativo**: Canal crítico para PyMEs/local, ignorado por enterprise
4. **Nicho geolocalizado**: Micro-negocios que Apollo/ZoomInfo no cubren

## Riesgos y Mitigaciones

| Riesgo | Mitigación |
|--------|-----------|
| Meta suspende cuentas WhatsApp | Verificación previa de números, rate limiting |
| Scraping bloqueado | Proxy rotation, user-agent rotation, respetar robots.txt |
| Warmup ineficaz | Gradual ramp-up (5→10→20 emails/día las primeras 2 semanas) |
| AI objeciones mal manejadas | Dial de autonomía permite revisión humana inicialmente |
